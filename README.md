# 黄谦 · 作品集（Portfolio）

海关业务 × AI 工程：把业务判断翻译成可测试、可审计的系统。

**线上地址**：https://dcd887.github.io/portfolio/

## 内容

| 板块 | 说明 |
|---|---|
| 关盾 Agent | 海关商品归类 AI 助手：证据链硬约束 + 多级模型降级 + 146 项可复现测试 |
| 税则通 | 微信小程序 + FastAPI：8972 条税则编码查询 |
| mcqa | Minecraft 整合包自动化 QA 框架 |
| 红楼推理 / 典藏司 | 以公有领域古籍为底的单文件解谜文游 |

## 技术

- 单文件 `index.html`，无构建步骤、无外部依赖，直接由 GitHub Pages 托管
- 简历 PDF 由 `_cv_map.txt` 映射；`robots.txt` 屏蔽 PDF 收录

## 本地预览

```bash
python -m http.server 8000    # 然后打开 http://localhost:8000
```
